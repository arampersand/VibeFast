## Semana 1 — Introducción y teoría

### Expectativa del curso

Vas a salir con un **asistente de voz personal**: hablas → una IA responde → oyes la respuesta en el kit. No necesitas experiencia previa en electrónica. Sí necesitas haberte sentido cómodo pidiéndole código a una IA (Cursor / Claude) y usando una laptop con Windows 10+, macOS o Linux.

### Conceptos (en orden)

1. **Microprocesador** — el “cerebro” chiquito de la placita; ejecuta el programa que le cargas.
2. **ESP32** — placita con WiFi/Bluetooth; punto intermedio entre Arduino (muy básico) y Raspberry (casi una PC). Detalle en [Hardware · ESP-Claw](/docs/features/hardware-esp-claw).
3. **Puertos / pines** — entradas y salidas: aquí enchufas LED, micrófono, bocina, etc.
4. **Protoboard** — tablilla donde los cables hacen contacto sin soldar.
5. **Cursor + IA** — tú describes el kit y el objetivo; la IA propone pines y código; tú pruebas y ajustas.
6. **PlatformIO** — desde el editor carga el programa al ESP32 con configuraciones que ya existen (menos pelea que el flujo clásico de Arduino a mano).

### Primer logro de la semana 1: el LED

Antes de armar todo el kit:

1. Conecta el ESP32 a la laptop con un **cable USB de datos** (no solo de carga).
2. Identifica el **puerto** que aparece en la compu (Device Manager / System Information).
3. Con PlatformIO + Cursor, carga el ejemplo “hello LED” (`firmware/examples/01-hello-led/` cuando esté publicado).
4. Si el LED parpadea: cable, driver y placita están bien. Si no: copia el error tal cual a la IA.

De poquito a poquito: primero placita sola, después un módulo, después el resto.

## Semana 2 — Armado en protoboard

### Qué hace el equipo docente vs qué haces tú

| Equipo docente | Tú |
|---|---|
| Entrega el ESP32 con pines listos (sin que tengas que soldar) | Conectas cables en la protoboard |
| Kit y lista de componentes | Sigues el mapa de pines (o se lo pides a la IA) |
| Soporte en vivo | Iteras si algo no prende |

### Pasos

1. **PlatformIO configurado** — preset del ESP32 del curso; puerto USB correcto.
2. **Verificar puerto** otra vez con el kit ya en tu mesa.
3. **Armar en protoboard** — micrófono / bocina / LED según la lista del kit. Un módulo a la vez si se traban.
4. **Prompt útil para la IA** (cópialo y completa):

```
Tengo un ESP32 y protoboard.
Componentes: [pega la lista del kit].
Quiero conectar [LED / micrófono / bocina] para probar.
Devuélveme: (1) tabla pin → cable → componente, (2) código PlatformIO mínimo para probarlo, (3) cómo sé en la laptop que el puerto es el correcto.
```

5. **Probar** cada conexión antes de pasar a la semana del asistente de voz.

## Prepárate desde ahora

1. Laptop con SO que conozcas (Windows 10/11, macOS o Linux) y cable USB de **datos**.
2. Cuenta de Cursor (o Claude) ya usada para un proyecto real — el filtro del curso apunta a eso.
3. Si vienes de vibecoding: trae fresco cómo leer un error y pegárselo a la IA.
4. No hace falta comprar herramientas de soldadura.

## Concepto: el cerebro no está en la placita

El ESP32 **captura y reproduce** audio (y habla por WiFi). La **inferencia** — entender lo que dijiste y generar la respuesta — la hace un modelo en la nube (ChatGPT, Claude, etc.) vía una petición (API / endpoint).

```
Micrófono → (audio) → puente/API → modelo de IA
                              ↓
Bocina    ← (audio) ← respuesta del modelo
```

No necesitas “entrenar” el modelo en clase. Usas un modelo ya entrenado: le mandas el audio (o el texto transcrito) y recibes la respuesta. Iterar prompts y el código del puente **sí** es parte del trabajo (vibecoding).

## Prepárate desde ahora

1. **Semanas 1–2 listas**: placita flasheable, LED ok, cables del kit en su sitio.
2. **Cuenta de API** según indique el docente (OpenAI u otra) — key solo en variables de entorno / secretos, nunca en un chat público.
3. **Una frase de producto**: “Mi asistente sirve para ___ cuando yo digo ___.” Eso acota el demo.

## Pasos de la semana (con el ejemplo publicado)

1. Cargar `firmware/examples/03-voice-assistant/` (o el repo que pase el equipo).
2. Configurar WiFi + clave de API como indique la guía (no hardcodear en capturas ni en Classroom).
3. Probar ida y vuelta: una frase corta al mic → respuesta audible.
4. Ajustar con Cursor: errores de red, de permisos de API, de volumen / pines de audio — siempre pegando el error completo.
5. (Opcional, track vibecoding) Enlazar el dispositivo a tu web app más adelante; ver [Hardware · ESP-Claw](/docs/features/hardware-esp-claw) y MCP cuando el bridge esté activo en el boilerplate.

## Entregable

Demo del asistente de voz funcionando de punta a punta + (si el programa lo pide) nota de 3–5 líneas: qué hace, qué API usa, qué limitación viste.

## Si algo no jala (orden de chequeo)

1. ¿El LED de la semana 1 sigue respondiendo? Si no, es cable/puerto, no la IA.
2. ¿La placita tiene WiFi al router del salón / hotspot de prueba?
3. ¿La API key es válida y tiene crédito?
4. Recién entonces: logs del puente y prompt a la IA con el error completo.
